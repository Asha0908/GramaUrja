# GRAMA URJA

Grama-Urja is a smart rural energy monitoring Android application designed to help farmers and village communities track real-time electricity availability.

## Features
- Real-time transformer status updates
- Crowdsourced power monitoring system
- Instant power outage alerts
- Helps farmers plan irrigation pump usage

## Technologies Used
- Android Studio (Kotlin / Java)
- Firebase (Firestore / Realtime Database)
- Push Notifications

## Problem Solved
Unpredictable electricity supply in rural areas causes inefficient irrigation and wasted time. This app provides real-time power status updates.

## Goal
To improve rural energy management and reduce electricity wastage.
